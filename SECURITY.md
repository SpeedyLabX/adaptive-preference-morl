# Security Policy

## Scope

This repository contains research code, frozen experiment protocols, evaluation tooling,
versioned JSON evidence, and a local-only inference demo (`127.0.0.1`). It does not host
production services or store credentials, model checkpoints, or private user data.

## Reporting a Vulnerability

If you discover a security issue (such as unsafe deserialization, path traversal in the
local demo/monitor servers, or accidentally committed sensitive information), please
report it privately to the [SpeedyLabX](https://github.com/SpeedyLabX) maintainers via
GitHub Security Advisories rather than opening a public issue.
